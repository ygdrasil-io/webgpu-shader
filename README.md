# Shader DSL

This is an experimental Kotlin Multiplatform DSL for generating shader code using a type-safe builder pattern. It uses WGSL (WebGPU Shading Language) as a reference for its syntax and currently exports to WGSL, but it could be extended to support other languages in the future.

## Features

- Type-safe shader construction
- Support for WGSL syntax
- Multiplatform compatibility (JVM, JS, Native)
- Extensible architecture for future language support

## Usage

This project is currently experimental and under active development. The API may change significantly in future versions.
